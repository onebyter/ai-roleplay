# AI RolePlay - 需求文档

## 1. 项目概述

开发一款支持多智能体角色扮演的桌面软件。界面风格参考 Cherry Studio（群聊方式），每个角色由独立 AI 智能体控制，世界背景和运行逻辑由单独智能体接管。

## 2. 目标用户

- 角色扮演爱好者
- 小说创作者（需要与笔下角色互动）
- TRPG 玩家（需要 GM 工具）
- AI 对话体验者

### 3.2 详细需求

#### F-001 多角色群聊对话
- 界面为群聊样式，每条消息显示角色头像 + 名称 + 内容
- 不同角色使用不同气泡颜色
- GM 发言（旁白）使用特殊样式（斜体/不同背景）
- 系统消息居中显示
- 消息支持 Markdown 渲染

#### F-002 角色独立 AI 智能体
- 每个角色有独立的 system prompt
- 每个角色可配置不同的 API/模型
- 角色记忆系统：短期记忆（最近对话）+ 长期记忆（关键事件）
- 角色一致性维护

#### F-003 GM 主导模式
- 用户切换为 GM 后，输入框变为叙事输入
- GM 可描述场景、控制 NPC、判定行动结果
- GM 决定发言顺序
- GM 可修改世界状态

#### F-004 自由群聊模式
- 角色根据上下文相关性自动决定是否发言
- 相关性评估机制
- 防抖机制：限制每轮最多 2-3 个角色回复
- 用户可随时插入发言

#### F-005 角色卡管理
- 表单化编辑：名称、描述、性格、说话风格、系统提示词等
- 角色列表展示 + 拖拽排序
- 角色导入/导出

#### F-006 存档/读档
- 完整会话快照（消息、角色状态、世界状态、智能体记忆）
- 自动保存 + 手动存档槽位
- 存档列表管理

#### F-007 世界设定管理
- 世界背景描述
- 世界规则列表
- LoreEntry 关键词匹配（对话中出现关键词时自动注入相关设定）
- 世界状态追踪（时间、地点、环境）

#### F-008 小说角色提取
- 导入 txt 小说文件
- LLM 自动分析识别出场人物
- 为每个角色生成：姓名、外貌、性格、说话风格、关系
- 用户审核并编辑提取结果

#### F-010 多 API 配置
- 预置 DeepSeek、MIMO、OpenAI 等服务商
- 用户可添加任意 OpenAI 兼容 API
- 每个角色可独立配置使用不同的 API/模型

### 3.3 UI/UX 设计需求

> 整体风格参考 Cherry Studio：现代化、简洁、沉浸感强

#### F-013 现代化 UI 设计
- 整体风格：简洁现代，参考 Cherry Studio / VSCode 的设计语言
- 间距与留白：合理使用 padding/margin，避免元素拥挤
- 圆角设计：卡片、按钮、输入框统一使用圆角（8px）
- 阴影层次：适当使用阴影区分层级（侧边栏 < 聊天区 < 弹窗）
- 图标系统：使用统一的图标库（Lucide Icons）
- 字体：正文 14px，标题 16-20px，辅助文字 12px

#### F-014 暗色主题
- 主背景色：深蓝黑（#1a1a2e）
- 次级背景：深蓝（#16213e）
- 强调色：紫蓝（#6c63ff）
- 文字颜色：主文字 #e8e8e8，辅助文字 #a0a0b0
- 边框：低对比度（#2a2a4a）
- 气泡样式：用户气泡用强调色，AI 气泡用次级背景
- GM 叙述：粉色左边框 + 半透明粉色背景
- 后续可扩展亮色主题

#### F-015 动画与过渡效果
- 消息出现：新消息淡入 + 轻微上滑
- 侧边栏切换：Tab 切换有下划线滑动动画
- 按钮交互：hover 时轻微放大或变色
- 面板展开/收起：平滑宽度过渡
- 打字指示器：三个点脉冲动画
- 流式输出：文字逐字出现，无卡顿

#### F-016 响应式布局
- 最小窗口：1000 x 700
- 三栏布局：侧边栏固定 256px，聊天区自适应，右侧面板 288px 可收起
- 窗口缩小时：右侧面板优先收起，侧边栏可折叠
- 聊天区消息：最大宽度 70%，长文本自动换行

## 4. 非功能需求

| 编号 | 需求 | 说明 |
|------|------|------|
| NF-001 | 跨平台 | 支持 Windows、macOS、Linux |
| NF-002 | 性能 | 100+ 条消息长对话流畅 |
| NF-003 | 数据安全 | API Key 本地存储，不上传 |
| NF-004 | 中文支持 | 界面中文，LLM 输出中文 |

## 5. 技术栈

| 层级 | 技术 |
|------|------|
| 桌面框架 | Electron + TypeScript |
| 前端 | React 18 + Shadcn/ui + Tailwind CSS |

| 数据库 | SQLite (sql.js - WASM 实现，无需原生编译) |
| LLM SDK | openai (npm) - 兼容所有 OpenAI 格式 API |
| 构建 | Vite + Electron Forge |
