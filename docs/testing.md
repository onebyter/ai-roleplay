# AI RolePlay - 功能测试文档

## 测试说明

本文档列出每个版本需要手动测试的功能点。请按顺序逐项测试，记录测试结果。

**测试结果标记**:

- ✅ 通过 - 功能正常
- ❌ 失败 - 功能异常（请在备注中描述问题）
- ⏭️ 跳过 - 暂不测试
- 🔧 修复中 - 已知问题，正在修复

**测试流程**:
1. 按版本顺序逐项测试
2. 发现问题 → 在"结果"列标记 ❌，在"备注"描述现象
3. 开发者修复后 → 在对应版本下方新增"回归验证"条目
4. 回归验证通过 → 标记 ✅；仍失败 → 标记 ❌ 继续修复
